# 🚀 Подобрена BI Система за Анализ - Ultimate Edition

Мощен Business Intelligence инструмент за анализ на CSV данни с интерактивни визуализации и експорт функции.

## ✨ Основни възможности

- 📊 **Анализ на CSV файлове** - автоматично разпознаване и обработка
- 📈 **Интерактивни графики** - различни типове визуализации  
- 🌐 **Мрежов анализ** - връзки между данните
- 💡 **Бизнес инсайти** - автоматични препоръки
- 📋 **Интерактивен дашборд** - обобщена информация
- 📄 **PDF експорт** - генериране на отчети
- 🔍 **Филтриране и сортиране** на данни

## 🚀 Как да започнем

### 1. Отваряне на приложението
- Отворете `index.html` в браузър
- Използвайте съвременен браузър (Chrome, Firefox, Edge)

### 2. Логин
- **Потребител:** `admin`
- **Парола:** `admin123`

### 3. Качване на данни
- Използвайте "Избери файл" бутона
- Поддържани формати: CSV файлове
- Данните ще бъдат анализирани автоматично

## 🔧 Технически детайли

- **Фронтенд:** Pure HTML5, CSS3, JavaScript (ES6+)
- **Библиотеки:** Chart.js, jsPDF
- **Поддържани браузъри:** Chrome 80+, Firefox 75+, Edge 80+
- **Файлови формати:** CSV (с автоматично разпознаване на колони)
